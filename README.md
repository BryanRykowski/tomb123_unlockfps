***Updated for Challenge Mode patch (2026-03-12)***

A script to unlock the framerate of the Steam version of Tomb Raider I-III Remastered in classic mode.

Intended for the 2026-03-12 "Challenge Mode" update. This is based on a technique described by MuruCoder at https://www.tombraiderforums.com/showthread.php?t=229926\ . This script must be run from the game's executable directory (where tomb123.exe is).
The simplest way is to copy this file to that directory and (from in that directory) run:
```
./tomb123_unlockfps.bash
```
